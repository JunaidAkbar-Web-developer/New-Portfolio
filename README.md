Modern Personal Portfolio:
A create, responsive, and interactive personal portfolio website built with HTML5, CSS3, and JavaScript. This project showcases professional experience, technical skills, and past projects with a focus on clean design and user experience

Features
Responsive Design: Fully optimized for desktops, tablets, and mobile devices.

Dark/Light Mode: Integrated theme switcher for a personalized viewing experience.

Interactive UI: Includes a typing effect in the hero section and a testimonial carousel.

Skill Visualization: Technical skills displayed via progress bars and professional skills via circular percentage charts.

Multi-Page Navigation: Clean navbar with links to dedicated sections for Education, Services, and Projects.

Functional Sections:

Hero: Strong introduction with social media links.

Education: A vertical timeline of academic history.

Portfolio: Grid layout for showcasing recent work.

Contact Form: Ready-to-use UI for user inquiries.

Built With:
HTML5: Semantic structure.

CSS3: Custom styling, Flexbox, Grid, and Animations.

JavaScript: Logic for theme toggling, mobile menu, and interactive elements.

Icons: Boxicons and Font Awesome.
